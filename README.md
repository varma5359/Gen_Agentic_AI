## Teaching standard

- Teach from beginner level before introducing intermediate examples.
- Explain code line by line, including methods, functions, arguments, parameters, return values and expected output.
- Use small, runnable code examples and realistic scenarios.
- Explain common errors and how to debug them.
- Keep class notes and interview preparation in separate files.
- Follow the approved day-wise syllabus and project titles.
- Do not inflate content with repetition; clarity and correctness come first.

Detailed materials are developed phase by phase. A day is listed as completed only after its class notes and interview file have been created and verified.
