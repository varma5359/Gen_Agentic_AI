# TechPhile.ai — GenAI & Agentic AI Developer Pathway

A self-learning, beginner-first 70-day pathway.

**Learning philosophy: No trainer. No video dependency.** Written lessons act as the student's technical mentor: explain concepts from zero, demonstrate code step by step, show expected output, troubleshoot errors and connect learning to projects and interviews.

## Source of truth

[10.Gen_Agentic.md](10.Gen_Agentic.md) contains the approved 70-day syllabus, nine phases, day titles, daily project titles and capstone specifications. This syllabus remains unchanged.

## Daily learning package

Each day has three independent files:
- **Class notes:** beginner-to-industry explanations and guided code.
- **Interview guide:** core questions with practical answers and follow-ups.
- **Project guide:** requirements, ordered implementation tasks, tests, evidence and submission criteria.

## How students should study

1. Read the class note in order.
2. Type and run every code example.
3. Compare actual output with expected output.
4. Complete independent practice.
5. Attempt the project before seeking a complete solution.
6. Answer interview questions aloud or in writing.
7. Keep evidence: code, test output, API responses and a project explanation.

## Quality and safety

- Never commit API keys, passwords, access tokens or private/customer data.
- Use a virtual environment for Python dependencies.
- Validate external input and handle errors deliberately.
- Treat examples as learning implementations, not automatically production-ready systems.
- Preserve approved day titles and project titles from the roadmap.
