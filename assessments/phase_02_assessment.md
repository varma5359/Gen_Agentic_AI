# Phase 2 Assessment — Generative AI and LLM Foundations

**Coverage:** Days 11–15  
**Approved phase outcome:** Understand basic working concepts of generative AI, LLMs and prompt engineering.

## Instructions
- Complete after studying all five days.
- Explain concepts in your own words.
- Show calculations and practical evidence.
- Do not claim a model/API was tested if you did not run it.
- Remove keys and private information from evidence.

## Part A — Concept understanding (20 points)
1. Differentiate AI, ML, deep learning, GenAI and LLMs. (4)
2. Draw and explain a high-level transformer/token-generation flow. (4)
3. Explain tokenisation, token IDs and context windows. (4)
4. Explain temperature, top-p and max output tokens. (4)
5. Explain hallucinations and three application safeguards. (4)

## Part B — Practical work (30 points)
Submit:
1. Generative AI Concept Explorer (5)
2. LLM Token and Context Window Analyzer (5)
3. LLM Generation Parameter Experiment (6)
4. Business Text Classification Prompt Application (7)
5. Reusable Business Prompt Library (7)

Each practical needs source, run instructions, test evidence and a short explanation. Where provider access is unavailable, label the work offline/planned rather than fabricating results.

## Part C — Reasoning (20 points)
1. A support assistant invents a refund policy. Explain likely causes and design a safer workflow. (5)
2. A request exceeds context capacity. Propose a token-budget strategy without discarding essential evidence. (5)
3. A classification prompt works on examples but fails on ambiguous messages. Improve taxonomy and test set. (5)
4. Prompt v2 improves three examples but breaks two earlier cases. Explain the regression process. (5)

## Part D — Quality and testing (15 points)
- Code readability and modularity (3)
- Input validation and error handling (3)
- Representative normal, boundary and invalid tests (3)
- Evidence and reproducibility (3)
- Limitations and security/privacy awareness (3)

## Part E — Interview and communication (15 points)
Prepare a five-minute explanation of:
- AI → ML → DL → GenAI → LLM relationship;
- transformer high-level flow;
- token and context budgeting;
- generation settings and hallucination safeguards;
- zero-shot/few-shot and reusable prompt testing.

Answer at least five interview questions from the daily guides. (15)

4. Modify a project or test to demonstrate understanding.
